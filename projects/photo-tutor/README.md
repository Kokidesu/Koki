# 📸 写真で学ぶ AI 家庭教師 / Photo Study Tutor（無料）

問題集・過去問・参考書の**写真をアップロード**すると、AI（画像認識）が
**答え＋「なぜそうなるか」の解説**を日本語・英語で返してくれる学習用チャットボットです。

**Google Gemini の無料API**で動くので、個人の学習用途なら基本無料で使えます。

> ⚠️ **学習・復習専用です。** 試験本番中の使用はカンニングにあたります。絶対に使わないでください。

## 特長
- 📷 **写真対応** — 図形・グラフ・表・回路図・手書きも読み取り
- 🧠 **どんな科目・難易度でもOK** — 数学/理科/英語/読解/SPI・玉手箱などの適性検査ほか
- ⚡ **モード切替** — 「高速（即答）」「標準」「高精度（難問向け）」
- 🌐 **日英対応** — 回答言語・画面言語をそれぞれ選択可
- 🆓 **無料** — Google AI Studio の無料APIキーを使用
- 🔒 **サーバー不要** — APIキーは**あなたのブラウザ内（localStorage）にだけ**保存。どこにも送信しません

## 使い方
1. このフォルダの `index.html` をブラウザで開く（公開URL: https://kokidesu.github.io/koki/photo-tutor/ ）
2. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) で **無料のAPIキー**を発行して入力 →「保存」
3. 問題の**写真をアップ**（複数枚OK・貼り付け・ドラッグ&ドロップ対応）
4. 必要なら補足質問を書いて「**解答する / Solve**」

## 仕組み（技術メモ）
- モデル: Google Gemini（無料枠 / Google AI Studio）
- ブラウザから `https://generativelanguage.googleapis.com/v1beta/models/{model}:streamGenerateContent`
  に直接リクエスト（ストリーミング表示）
- 単一HTMLファイルのみ。ビルド・依存パッケージ・サーバーなし。

### モード別のモデル
| モード | モデル | 用途 |
|--------|--------|------|
| ⚡ 高速 | `gemini-2.0-flash` | とにかく速く答えがほしい |
| ⚖️ 標準 | `gemini-2.5-flash` | バランス（既定） |
| 🎯 高精度 | `gemini-2.5-pro` | 難問重視（無料枠の上限は標準より厳しめ） |

## 注意
- **無料枠のデータ利用について:** Google AI Studio の無料枠では、入力した内容が
  Googleの品質改善に使われる場合があります（有料枠では使われません）。気になる内容は避けてください。
- 無料枠には1分あたり・1日あたりのリクエスト上限があります。上限に達したらしばらく待つか、
  モードを「標準/高速」に下げてください。
- APIキーをブラウザに保存するため、**自分の端末でのみ**使ってください（共有PC非推奨）。
- 画像が不鮮明だと精度が落ちます。明るく・まっすぐ・問題全体が入るように撮影してください。
