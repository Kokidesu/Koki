# 📸 写真で学ぶ AI 家庭教師 / Photo Study Tutor

問題集・過去問・参考書の**写真をアップロード**すると、Claude（画像認識）が
**答え＋「なぜそうなるか」の解説**を日本語・英語で返してくれる学習用チャットボットです。

> ⚠️ **学習・復習専用です。** 試験本番中の使用はカンニングにあたります。絶対に使わないでください。

## 特長
- 📷 **写真対応** — 図形・グラフ・表・回路図・手書きも読み取り（高解像度Vision）
- 🧠 **どんな科目・難易度でもOK** — 数学/理科/英語/読解/SPI・玉手箱などの適性検査ほか
- ⚡ **モード切替** — 「高速（即答）」「標準」「高精度（難問も検算）」
- 🌐 **日英対応** — 回答言語・画面言語をそれぞれ選択可
- 🔒 **サーバー不要** — APIキーは**あなたのブラウザ内（localStorage）にだけ**保存。どこにも送信しません

## 使い方
1. このフォルダの `index.html` を**ブラウザで開く**（ファイルをダブルクリックでOK）
2. [console.anthropic.com](https://console.anthropic.com/settings/keys) で発行した **Anthropic API キー**を入力して「保存」
3. 問題の**写真をアップ**（複数枚OK・貼り付け・ドラッグ&ドロップ対応）
4. 必要なら補足質問を書いて「**解答する / Solve**」

## 仕組み（技術メモ）
- モデル: `claude-opus-4-8`（Vision + adaptive thinking）
- ブラウザから `https://api.anthropic.com/v1/messages` に直接リクエスト
  （`anthropic-dangerous-direct-browser-access: true` ヘッダーを使用、ストリーミング表示）
- 単一HTMLファイルのみ。ビルド・依存パッケージなし。

### モード別の設定
| モード | thinking | effort | 用途 |
|--------|----------|--------|------|
| ⚡ 高速 | off | low | とにかく速く答えがほしい |
| ⚖️ 標準 | adaptive | medium | バランス（既定） |
| 🎯 高精度 | adaptive | high | 難問・検算重視 |

## 注意
- APIキーをブラウザに保存するため、**自分の端末でのみ**使ってください（共有PC非推奨）。
- 画像が不鮮明だと精度が落ちます。明るく・まっすぐ・問題全体が入るように撮影してください。
- API利用にはAnthropicの従量課金が発生します。
