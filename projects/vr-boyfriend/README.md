# みーくん — VR彼氏アプリ

るーちゃん専用の、やさしい彼氏「みーくん」と話せる単一HTMLのWebアプリ。

公開URL（GitHub Pages）: https://kokidesu.github.io/koki/vr-boyfriend/

## 特長
- 💬 **チャット**：みーくんが「るーちゃん」と呼んで甘く返事してくれる
- 🫶 **いこいこモード（いい子いい子）**：頭をなでて、ひたすら褒めて甘やかしてくれるモード
- 🔊 **声で話す**：端末の音声合成（Web Speech API）で読み上げ（ON/OFF可）
- 💕 **没入モード**：ときどきみーくんの方から話しかけてくる
- 🖼️ **写真アバター**：`miikun.jpg` をそのままみーくんの画像として表示
- ⚙️ **設定**：彼氏／彼女の名前、声、没入モードを変更可能（端末内に保存）

## かしこモード（任意）
設定で **Gemini APIキー** を入れると、会話がより自然になります。
- キーは端末（localStorage）にのみ保存され、Google API以外には送信しません。
- 未入力でも、内蔵の性格で普通に会話できます。
- キー取得: https://aistudio.google.com/apikey

## 使い方
`index.html` をブラウザで開くだけ。サーバー不要・完全クライアント動作。

## 構成
- `index.html` … アプリ本体（HTML/CSS/JS 一体）
- `miikun.jpg` … みーくんのアバター画像

## 名前を変えたいとき
画面右上の ⚙️ から、彼氏／彼女の名前をいつでも変更できます。
